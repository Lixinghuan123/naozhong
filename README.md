# Web闹钟应用

一个功能完整的Web版闹钟应用，具有现代化的界面和丰富的功能。

## 🎯 功能特性

### 1. 基本闹钟功能
- ⏰ 设置多个闹钟
- 📅 选择提醒日期和时间
- 💬 添加闹钟标题（最多200字）
- 🔔 多种提醒方式：
  - 响铃提醒（使用Web Audio API生成）
  - 震动提醒（需要设备支持）
  - 语音提醒（使用Web Speech API）

### 2. 周期提醒
- 🔄 支持多种重复周期：
  - 不重复（仅一次）
  - 每隔几分钟
  - 每隔几小时
  - 每隔几天
- ⏳ 响铃后需手动停止，否则持续提醒

### 3. 日历集成
- 📆 使用FullCalendar显示所有闹钟
- 🎨 不同颜色标记不同闹钟
- 📅 点击日期快速设置闹钟
- 🔍 月视图、周视图、日视图切换

### 4. 悬浮球设计
- 🎈 右下角悬浮球按钮，快速访问
- 📊 分离的闹钟设置面板和日历面板
- 📱 响应式设计，支持移动设备

## 🚀 快速开始

### 本地运行

1. **克隆或下载项目**
   ```bash
   git clone <repository-url>
   cd naozhong
   ```

2. **启动本地服务器**
   - 使用Python:
     ```bash
     python -m http.server 8000
     ```
   - 使用Node.js (需要安装http-server):
     ```bash
     npx http-server -p 8000
     ```
   - 使用PHP:
     ```bash
     php -S localhost:8000
     ```

3. **访问应用**
   在浏览器中打开 `http://localhost:8000`

### 直接打开

你也可以直接双击 `index.html` 文件在浏览器中打开，但某些功能（如通知、语音）可能受浏览器限制。

## 📖 使用说明

### 设置闹钟

1. 点击右下角的 ⏰ 悬浮球按钮
2. 填写闹钟标题（最多200字）
3. 选择提醒日期和时间
4. 设置重复周期（可选）
5. 选择提醒方式
6. 点击"保存闹钟"按钮

### 管理闹钟

- 在闹钟面板中可以查看所有已设置的闹钟
- 点击"删除"按钮移除不需要的闹钟
- 闹钟会自动保存到浏览器本地存储

### 使用日历

1. 点击右下角的 📅 悬浮球按钮打开日历
2. 查看所有闹钟在日历上的分布
3. 点击任意日期快速设置该日期的闹钟
4. 使用顶部按钮切换视图（月/周/日）

### 处理提醒

- 当闹钟触发时，会显示提醒对话框
- 点击"停止闹钟"立即停止所有提醒
- 点击"稍后提醒"将在5分钟后再次提醒

## 🛠️ 技术栈

- **HTML5** - 页面结构
- **CSS3** - 样式设计
- **JavaScript (ES6+)** - 功能实现
- **FullCalendar 6** - 日历组件
- **Web API** - 原生浏览器API
  - LocalStorage - 数据存储
  - Web Audio API - 音频生成
  - Web Speech API - 语音合成
  - Vibration API - 设备震动
  - Notification API - 桌面通知

## 📝 注意事项

1. **权限要求**
   - 语音提醒需要麦克风/语音合成权限
   - 震动提醒需要设备支持
   - 桌面通知需要通知权限

2. **数据存储**
   - 闹钟数据保存在浏览器本地存储中
   - 清除浏览器数据会丢失闹钟设置
   - 建议定期备份重要的闹钟

3. **浏览器限制**
   - 某些浏览器在后台可能会限制定时器
   - 建议将应用添加到桌面或书签
   - 保持浏览器标签页打开以确保提醒准时

4. **悬浮球功能**
   - 实现了固定定位的悬浮按钮
   - 由于浏览器安全限制，无法实现系统级悬浮球
   - 在页面内提供了类似的便捷访问方式
