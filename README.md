# Web闹钟应用

一个功能丰富、界面现代化的Web版闹钟应用，支持多种重复模式和通知方式。

## 功能特性

### 🎯 核心功能
- **闹钟管理**: 添加、编辑、删除闹钟
- **开关控制**: 随时启用/禁用闹钟
- **实时显示**: 当前时间和日期显示
- **本地存储**: 闹钟设置自动保存到浏览器本地存储

### ⏰ 重复设置
- **仅一次**: 仅在指定日期响铃（支持多选日期）
- **每天**: 每天固定时间响铃
- **间隔重复**: 按分钟或小时间隔重复响铃

### 🔔 通知方式
- **音乐播放**: 响铃时播放提示音
- **语音播报**: 使用Web Speech API语音播报闹钟标题

### 🎨 界面设计
- **现代化UI**: 渐变背景、圆角卡片、流畅动画
- **响应式设计**: 适配桌面和移动设备
- **交互反馈**: 悬停效果、点击动画、过渡动画
- **深色主题**: 弹窗使用渐变色设计

## 技术栈

- **HTML5**: 语义化标签
- **CSS3**: Flexbox、Grid、动画、渐变
- **JavaScript ES6+**: 类、箭头函数、模板字符串
- **Web API**: LocalStorage、AudioContext、SpeechSynthesis
- **外部资源**: Font Awesome图标、Google Fonts字体

## 使用方法

### 1. 添加闹钟
1. 点击"添加闹钟"按钮
2. 填写闹钟标题
3. 设置响铃时间
4. 选择重复模式：
   - **仅一次**: 选择具体响铃日期（可多选）
   - **每天**: 每天自动响铃
   - **间隔重复**: 设置间隔时间和单位（分钟/小时）
5. 选择通知方式（音乐播放/语音播报）
6. 点击"保存闹钟"完成添加

### 2. 管理闹钟
- **启用/禁用**: 点击闹钟右侧的开关按钮
- **编辑**: 点击编辑图标修改闹钟设置
- **删除**: 点击删除图标移除闹钟

### 3. 响铃处理
- **稍后提醒**: 点击"稍后提醒（5分钟）"按钮，5分钟后再次响铃
- **关闭闹钟**: 点击"关闭闹钟"按钮停止响铃

## 特色功能详解

### 日期选择器
- 显示未来30天的日期
- 支持多选日期
- 点击日期即可切换选择状态
- 直观的视觉反馈

### 间隔重复
- 灵活的间隔设置（1分钟到24小时）
- 支持分钟和小时两种单位
- 基于上次响铃时间计算下次响铃

### 语音播报
- 使用系统默认语音合成
- 支持中文普通话
- 可单独开启或关闭

## 开发说明

### 代码结构
应用采用面向对象编程，主要类：

```javascript
class AlarmApp {
    constructor()        // 初始化应用
    initElements()       // 获取DOM元素
    initEventListeners() // 绑定事件监听器
    renderAlarms()       // 渲染闹钟列表
    checkAlarms()        // 检查是否有闹钟需要响铃
    triggerAlarm()       // 触发闹钟响铃
    saveAlarms()         // 保存到本地存储
    loadAlarms()         // 从本地存储加载
}
```

### 数据存储格式
```javascript
{
    id: 1234567890,           // 唯一标识
    title: "起床闹钟",         // 闹钟标题
    time: "07:30",           // 响铃时间
    repeatType: "daily",      // 重复类型: none/daily/interval
    interval: {               // 间隔设置（仅interval类型）
        value: 30,
        unit: "minutes"
    },
    dates: ["2024-01-01"],    // 响铃日期（仅none类型）
    playSound: true,          // 是否播放音乐
    voiceAnnounce: true,      // 是否语音播报
    enabled: true,            // 是否启用
    lastTriggered: null       // 上次响铃时间
}
```
