# 闹钟应用

一个现代化的Web版闹钟应用，具有丰富的功能和美观的界面。

## 功能特性

### 1. 闹钟管理
- 查看已设置的所有闹钟
- 启用/禁用闹钟
- 编辑闹钟
- 删除闹钟

### 2. 添加闹钟
- 设置闹钟标题
- 设置闹钟时间
- 三种重复模式：
  - 每天重复
  - 间隔重复（分钟/小时）
  - 特定日期重复（未来7天选择）
- 响铃方式：
  - 播放音乐（四种铃声可选）
  - 语音播报闹钟标题

### 3. 闹钟响铃
- 响铃弹窗提醒
- 稍后提醒（5分钟后再次响铃）
- 关闭闹钟

## 技术栈

## 安装与运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

应用将在 `http://localhost:42938` 启动

### 3. 生产构建

```bash
npm run build
```

构建产物将生成在 `build` 目录

### 4. 预览生产构建


## 使用说明

### 添加闹钟

1. 点击页面上方的"添加闹钟"按钮
2. 填写闹钟标题
3. 设置闹钟时间
4. 选择重复模式：
   - 每天：每天同一时间响铃
   - 间隔：每隔指定分钟/小时响铃
   - 特定日期：选择未来7天中的特定日期响铃
5. 选择响铃方式：播放音乐和/或语音播报
6. 选择铃声类型
7. 点击"保存闹钟"按钮

### 管理闹钟

- **启用/禁用**：点击闹钟右侧的开关按钮
- **编辑**：点击闹钟右侧的编辑按钮（铅笔图标）
- **删除**：点击闹钟右侧的删除按钮（垃圾桶图标）

### 闹钟响铃

- 当闹钟时间到达时，将弹出响铃提醒
- 点击"稍后提醒"按钮，5分钟后再次响铃
- 点击"关闭闹钟"按钮，停止响铃
