# 智能闹钟应用

一个功能丰富的Web版闹钟应用，具有现代化的界面和多种实用功能。

## 功能特点

### 1. 闹钟管理
- **添加闹钟**：支持设置闹钟标题、时间、重复规则等
- **编辑闹钟**：随时修改已设置的闹钟信息
- **删除闹钟**：移除不需要的闹钟
- **启用/禁用**：快速开启或关闭闹钟

### 2. 重复规则
- **每天**：默认选项，每天同一时间响铃
- **间隔**：支持按分钟或小时间隔重复响铃
- **特定日期**：可选择多个具体日期响铃

### 3. 响铃设置
- **音乐选择**：提供多种响铃音乐供选择
- **语音播报**：支持语音播报闹钟标题（需要浏览器支持Web Speech API）

### 4. 响铃控制
- **停止响铃**：立即停止当前闹钟
- **稍后提醒**：10分钟后再次提醒

## 技术实现

### 前端技术栈
- **HTML5**：页面结构
- **CSS3**：样式设计（响应式布局、动画效果）
- **JavaScript (ES6+)**：功能逻辑

### 核心功能实现

#### 1. 闹钟存储
使用浏览器的`localStorage` API持久化存储闹钟数据。

#### 2. 闹钟检查
每分钟检查一次当前时间是否匹配任何已启用的闹钟时间。

#### 3. 音频播放
使用Web Audio API创建简单的提示音（实际应用中可替换为音频文件）。

#### 4. 语音播报
使用浏览器的Web Speech API实现语音合成功能。

#### 5. 日期选择器
自定义实现的日期选择器，支持选择多个特定日期。

## 使用说明

### 1. 添加闹钟
1. 点击页面中的"添加闹钟"按钮
2. 填写闹钟标题
3. 选择闹钟时间
4. 设置重复规则（可选）
5. 选择响铃音乐和是否启用语音播报
6. 点击"保存"按钮

### 2. 编辑闹钟
1. 找到要编辑的闹钟
2. 点击闹钟项中的编辑图标
3. 修改闹钟信息
4. 点击"保存"按钮

### 3. 删除闹钟
1. 找到要删除的闹钟
2. 点击闹钟项中的删除图标
3. 确认删除操作

### 4. 启用/禁用闹钟
1. 找到要操作的闹钟
2. 点击闹钟项右上角的开关按钮

## 开发说明

### 运行项目
直接在浏览器中打开`index.html`文件即可运行应用。

### 自定义响铃音乐
要添加自定义响铃音乐，可在`playAlarmSound`函数中修改音频文件路径。
